# 将 SSH KEY 配置到 GitHub

在github，点击右上角头像 选择settings，进入设置页后选择 SSH and GPG keys，名字为Hexo博客更新专用key，公钥填到Key那一栏。

# 测试连接，输入以下命令

ssh -T git@github.com
1

这里为了避免和默认GitHub连接出现冲突，在.ssh/文件夹下创建config文件，内容如下：

# 默认github（Ngkcvs）
Host github
    User git
    Hostname github.com
    PreferredAuthentications publickey
    IdentityFile ~/.ssh/id_rsa

# Ngkcvs2084cc
Host github-Ngkcvs2084cc
    HostName github.com
    User git
    IdentityFile ~/.ssh/Ngkcvs2084cc/id_rsa2084cc

New repository，创建一个<用户名>.github.io的仓库。即 Ngkcvs2084cc.github.io

# 2.初始化 Hexo 博客

1、在Git BASH中输入如下命令安装 Hexo

npm install -g hexo-cli && hexo -v	#安装和查看版本
hexo -v								#查看版本号
1
2

2、初始化 Hexo 项目安装相关依赖。

hexo init blog-demo
cd blog-demo
npm i
1
2
3

3、启动项目

hexo cl && hexo s
1

按ctrl+C关闭本地项目

4、部署到 GitHub Pages

npm install hexo-deployer-git --save    #安装 hexo-deployer-git
1

修改blog-demo目录下的_config.yml配置文件,他是整个Hexo框架的配置文件。可以在里面修改大部分的配置。详细可参考官方的配置描述 (opens new window)。

最后一行的配置，将repository修改为你自己的github项目地址即可，还有分支要改为main代表主分支（注意缩进）。

deploy:
  type: git
  repository: git@github-Ngkcvs2084cc:Ngkcvs2084cc/Ngkcvs2084cc.github.io.git
  branch: main

修改好配置后，运行如下命令，将代码部署到 GitHub（Hexo三连）。

# 3.安装博客主题等插件，使博客页面变得美观

1、在博客根目录里安装最新版主题

git clone -b main https://github.com/anzhiyu-c/hexo-theme-anzhiyu.git themes/anzhiyu
npm install hexo-renderer-pug hexo-renderer-stylus --save   #安装 pug 以及 stylus 的渲染器
1
2

修改_config.yml文件，把主题改为anzhiyu

https://github.com/Ngkcvs/picx-images-hosting/raw/master/image.5c182dj8f3.webp

覆盖配置：把主题配置放置在 anzhiyu 目录之外，避免在更新主题时丢失自定义的配置。

linux系统执行以下命令

bash
cp -rf ./themes/anzhiyu/_config.yml ./_config.anzhiyu.yml
1
2

windows系统 就手动将/themes/anzhiyu/_config.yml复制到根目录下并重命名为_config.anzhiyu.yml即可。以后如果修改任何主题配置，都只需修改 _config.anzhiyu.yml 的配置即可。

注意：
只要存在于 _config.anzhiyu.yml 的配置都是高优先级，修改原 _config.yml 是无效的。
每次更新主题可能存在配置变更，请注意更新说明，可能需要手动对 _config.anzhiyu.yml 同步修改。
想查看覆盖配置有没有生效，可以通过 hexo g --debug 查看命令行输出。
如果想将某些配置覆盖为空，注意不要把主键删掉，不然是无法覆盖的
